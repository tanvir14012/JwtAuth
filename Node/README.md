# Node.js

This folder contains the Node.js version of the app:

- `backend/`: Express.js API + MongoDB + JWT access/refresh token auth
- `frontend/`: Next.js frontend (App Router)

## Backend

1. Copy `backend/.env.example` to `backend/.env`
2. Update MongoDB and JWT settings
3. Install and run:
   - `npm install`
   - `npm run dev`

API runs by default at `http://localhost:4000`.

## Frontend

1. Copy `frontend/.env.local.example` to `frontend/.env.local`
2. Install and run:
   - `npm install`
   - `npm run dev`

Frontend runs by default at `http://localhost:3000`.
